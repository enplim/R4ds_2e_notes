Arithmetic and recycling rules

  • When the vector lengths are mismatched, the elements of the shorter vector is recycled or repeated:
x <- c(1, 2, 10, 20)
x / 5
## [1] 0.2 0.4 2.0 4.0
x / c(5, 5, 5, 5)
## [1] 0.2 0.4 2.0 4.0
  • R throws a warning when the length of the longer vector is not a multiple of the length of the shorter vector:
x * c(1, 2)
## [1]  1  4 10 40
x * c(1, 2, 3)
## Warning in x * c(1, 2, 3): longer object length is not a multiple of shorter
## object length
## [1]  1  4 30 20
  • Recycling rules are also applied to logical comparisons.

Logarithms

  • Useful for dealing with data that ranges across multiple orders of magnitude.
  • log2() and log10() are generally easier to interpret than logs of other bases.
  • In base 2, every one step “forward” corresponds to doubling on the original scale, and every step “backward” corresponds to halving – think of the f-stops in photography.

Rounding

  • Rounding to the nearest integer:
round(123.456)
## [1] 123
  • Changing the precision of rounding using the digits argument:
round(123.456, digits = 2)  # two digits to the right of decimal point
## [1] 123.46
round(123.456, 1)           # one digit...
## [1] 123.5
round(123.456, -1)          # nearest ten
## [1] 120
round(123.456, -2)          # nearest hundred
## [1] 100
  • R uses a rounding scheme called “Banker’s rounding” – a number halfway between two integers will be rounded to the even integer.
round(c(1.5, 2.5))
## [1] 2 2
  • Because of this rounding scheme, we need to use floor() or ceiling() if we want to specifically round up or round down:
x <- 123.456

floor(x)
## [1] 123
ceiling(x)
## [1] 124
  • Since floor() and ceiling() don’t have a digits argument, here’s a trick you can use to control the number of digits used in rounding:
# Round down to the nearest two digits
floor(x / 0.01) * 0.01
## [1] 123.45
# Round up to the nearest two digits
ceiling(x / 0.01) * 0.01
## [1] 123.46

Cutting numbers into ranges

  • Using cut() to break up a numeric vector into discrete buckets or bins:
x <- c(1, 2, 5, 10, 15, 20)

# With even spacing
cut(x, breaks = c(0, 5, 10, 15, 20))
## [1] (0,5]   (0,5]   (0,5]   (5,10]  (10,15] (15,20]
## Levels: (0,5] (5,10] (10,15] (15,20]
# With uneven spacing
cut(x, breaks = c(0, 5, 10, 100))
## [1] (0,5]    (0,5]    (0,5]    (5,10]   (10,100] (10,100]
## Levels: (0,5] (5,10] (10,100]
# breeaks with custom labels
cut(x,
  breaks = c(0, 5, 10, 15, 20),
  labels = c("small", "medium", "large", "extra_large")
)
## [1] small       small       small       medium      large       extra_large
## Levels: small medium large extra_large
  • Any values outside the range of breaks will become NA
y <- c(NA, -10, 5, 10, 30)
cut(y, breaks = c(0, 5, 10, 15, 20))
## [1] <NA>   <NA>   (0,5]  (5,10] <NA>  
## Levels: (0,5] (5,10] (10,15] (15,20]

Summary functions using mutate()

  • Useful when a standardized summary function is preferred.

Examples of mutate commands for summarizing data:
- x / sum(x) for getting the proportion of total.
- (x - mean(x)) / sd(x) for calculating the z-score (standardized to have a mean of 0 and sd of 1).
- (x - min(x)) / (max(x) - min(x)) for standardizing the data range to [0, 1].
- x / first(x) for generating an index based on the first observation.
